本机编辑与资料

公式、LaTeX 源码、计算结果和绘图内容在您的 Mac 上编辑与处理。工作簿保存在您选择的位置；自动保存、公式历史、最近关闭记录、自定义键盘、公式库与显示偏好保存在本机应用资料或网页视图的本机存储中，用于继续编辑和恢复内容。

符号计算使用随应用提供的本机数学组件。LaTeX 绘图通过您安装的 MacTeX / TeX Live 在本机编译。选择 iCloud、其他云盘或备份目录保存文件时，相应服务依据自己的规则同步和保存这些文件。

激活码与授权服务

设备码由本机设备标识的摘要生成，用于将授权与当前 Mac 关联。您复制设备码并提供给作者后，作者核实订单，再签发对应的激活码或 .qingshu-license 授权文件。应用在本机验证并保存授权，便于后续启动与离线使用。

激活服务涉及您主动提供的设备码、授权称呼、联系资料及订单核对信息。作者在本机授权管理工具中保存相关客户与授权记录，例如设备码、授权编号、签发日期、收款渠道、金额、币种及交易编号，用于核款、查询、补发和换机支持。

付款通过您与作者约定的收款渠道进行，相应平台依据自身规则处理支付资料。您可以通过联系邮箱沟通授权资料的查询、更正、删除和留存安排。

图片与公式识别

本机文字提取使用 Apple Vision，在 Mac 上提取您选择的图片或截图中的普通文字。在线公式识别将图片转写为 LaTeX，接收方是识别窗口中显示的服务主机和模型。

在线识别时，您先预览图片、核对接收服务与模型、勾选本次发送同意，再点击发送。请求通过 HTTPS 传送完整选定图片、公式转写提示和模型名称，并使用您提供的 API 密钥进行服务身份验证。图片中包含的文字、姓名等信息也属于本次传送内容，适合在预览时一并检查。

当前默认服务地址为 api.moonshot.cn，您也可以设置兼容的 HTTPS 图像输入服务。更换图片、服务、模型或密钥后，重新核对本次发送同意；每次发送对应您确认的图片与服务。

接收方依据自己的服务约定处理图片、请求日志、账号关联和数据权利请求。默认服务的具体规则可查看 Kimi 开放平台隐私政策及 API 数据处理说明。使用其他服务时，请查看该接收方的适用规则。

密钥与系统权限

识别服务的 API 密钥保存在 macOS 钥匙串，按服务主机名与端口区分；服务地址和模型名称保存在本机设置中。密钥通过独立凭据入口管理，公式与工作簿导出使用各自的内容格式。

您可以在识别设置中删除对应的本机密钥；服务账号中的密钥管理与撤销，可在服务提供者的账号页面办理。截图等系统权限由 macOS 管理，您可以在“系统设置 → 隐私与安全性”中调整。

文件与剪贴板

打开、保存、导入、导出、复制及粘贴由您的操作触发。应用可保留您选择文件的访问授权，以便继续保存该工作簿。主动截图时，所选屏幕区域用于本次文字提取或图片识别。

将公式、图片、源码或工作簿粘贴和分享给其他应用后，接收内容由对应应用或服务按其规则处理。导出文件可包含用于再次编辑的公式源码元数据，分享前可以按用途选择格式并检查内容。

资料保存与管理

您可以在各自保存位置管理工作簿、导出文件、云盘副本与备份。公式历史、最近关闭记录和回收站为恢复内容保留资料；需要整理本机自动保存和恢复资料时，可联系作者获取对应版本的操作方式，并先保存准备继续使用的文档。

您可以通过识别窗口管理每次发送同意、删除本机密钥，并通过 macOS 调整系统权限。已由在线识别服务接收的资料，其查询、更正与删除按该接收方的规则办理；作者接收到的激活与支持资料，可通过联系邮箱沟通具体处理方式。

网站访问
