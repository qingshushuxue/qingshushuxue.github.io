01 / 获取与激活

一次买断，在当前 Mac 长期使用。

激活码版使用与设备绑定的离线授权。一台 Mac 对应一份授权，完成激活后即可使用公式编辑、计算器和 LaTeX 绘图工作区。

  1. 联系作者，确认交付。通过邮箱了解当前版本、价格与交付方式，确认后由作者提供对应软件与授权。
  2. 打开软件，复制设备码。首次启动时，在激活页面复制当前 Mac 的设备码，发送给作者用于签发授权。
  3. 导入授权文件或粘贴激活码。收到 .qingshu-license 文件后，选择“导入授权文件”；也可粘贴作者提供的完整激活码，完成本机验证。
激活后怎样查看授权？

在顶部“帮助 → 激活与授权”查看当前 Mac 的授权状态。日常编辑、计算、工作簿管理与导出可在离线状态下进行。

重新安装或更换 Mac，怎样安排授权？

同一台 Mac 重新安装软件时，可以再次使用对应授权文件或激活码。更换 Mac 时，联系作者提供新设备码，办理重新签发。版本升级与换机安排可与作者一并确认。

授权文件怎样保存更方便？

将授权文件与购买记录保存在自己的备份位置，激活时直接选择文件。通过邮件保存的授权附件也可下载后导入。

安装包随软件提供本机计算组件和数学字体。普通公式编辑、格式交流和本机计算在完成激活后即可使用；真实 TeX 绘图编译配合本机 TeX 环境。

主窗口顶部可切换“公式编辑”“计算器”和“LaTeX 绘图”。“操作指南”集中介绍快捷键、输入结构、矩阵行列、复制导出、计算参数与绘图工具。

03 / TeX 绘图环境

用本机 TeX，完成正式图形输出。

TikZ、PGFPlots 等真实编译使用 MacTeX / TeX Live。进入“LaTeX 绘图”，在“TeX 环境”查看本机引擎与常用宏包的检测结果。

  1. 查看环境。打开“TeX 环境”，确认引擎与当前图形所用宏包。
  2. 按需安装。点“下载 TeX 安装包”进入官方下载流程。MacTeX 完整安装包为数 GB，大小以官网当前说明为准。
  3. 检测并编译。完成安装后回到软件选择“重新检测”，再执行“编译预览”，查看实际排版结果并导出。

交换图与几何图形可直接在画布组织节点、连接和坐标；正式编译时，源码交由选定的本机引擎处理。PNG、SVG、PDF 等导出入口与工程保存入口位于绘图工具栏。

04 / 工作簿与格式交流

让公式和成果随时接得上。

工作簿与公式怎样保存？

使用 ⌘S 保存 .mathstudio 工作簿，保留公式、源码和相关工作区内容。公式库可为常用公式命名、分组与收藏；自动历史和“最近关闭的工作簿”提供恢复入口。

重要资料适合同时保存工作簿副本与自己的备份。导出到云盘目录后，文件按所选云盘的同步设置管理。

怎样在其他应用中使用公式？

在公式画布选中需要的片段或整条公式，使用复制工具或右键菜单选择输出格式。LaTeX、MathML、UnicodeMath 等适合文本与数学格式交流；PNG、SVG、PDF 适合图片、矢量排版与打印。Office DOCX 导出提供可编辑公式，MathType 面板提供读取预览与互贴入口。

保留内嵌源码的导出文件可重新导入继续编辑。通过图片识别转写普通图片时，可先在预览中核对公式，再插入工作簿。

怎样安排更宽敞的编辑空间？

拖动键盘上沿调整高度，收起符号键盘或公式列表，调节公式显示大小。LaTeX 源码和绘图可以独立开窗，配合 macOS 分屏使用；多个工作簿也可分别打开。

05 / 图片识别

把图片中的数学内容接入工作簿。

本机文字提取使用 Apple Vision 处理选择的图片或截图区域。在线公式识别使用你配置的兼容 HTTPS 服务、视觉模型和 API 密钥，适合将公式图片转为 LaTeX。

每次在线识别先显示选定图片、接收服务与模型，确认本次发送后再执行识别。API 密钥保存在 macOS 钥匙串，识别结果可在预览中核对并插入公式。
