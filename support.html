怎样反馈更容易复现

  1. 说明环境。软件版本、macOS 版本及 Apple 芯片型号。
  2. 写下过程。从哪一步开始、按了什么、预期与实际结果是什么。
  3. 准备最小示例。公式问题附最小 LaTeX；绘图问题附最小源码与错误提示。
  4. 先检查附件。截图、工作簿和日志只保留适合发送的内容，先另存原稿。

请勿发送 API 密钥、银行卡信息、Apple 密码、授权发码资料或无关工作簿。作者只能接收您主动发来的内容，不会自动取得您的编辑资料。

试用、购买与恢复

50 个字符怎样计算？

按每条公式的 LaTeX 源码 Unicode 字符计数，汉字与扩展字符均各计一个。不是按排版后看见的符号数量计算。

已有长公式保持可读且不截断，可以继续删减。手动复制、保存或导出时，每条输出公式须不超过 50 字符，或先解锁；拒绝操作仍保留已编辑内容。

准备采用什么购买方式？

计划采用一次性 Apple 非消耗型应用内购买，无订阅，解锁不限长度公式编辑、计算器和 LaTeX 绘图。价格以正式配置后 Apple 返回的信息为准，当前未设定价格，也尚不可购买。

商店版不使用作者激活码。取消购买或处于待处理状态不会删除工作簿。

换电脑后怎样恢复？

正式商品配置并完成交易验收后，可在同一购买 Apple 账号下使用“帮助 → 购买与恢复”中的“恢复购买”重新核验，可能出现 Apple 登录。当前本地准备包尚未配置商品，不能据此完成真实购买或恢复。

文件与本机恢复资料

遇到编辑问题，先保留原工作簿，必要时另存副本。关闭工作簿后可从“最近关闭”恢复，公式历史回收站也可恢复；这些入口不是永久删除功能。

不要为排查问题直接清空本机应用资料。若需要清理自动保存或恢复副本，可联系作者核对当前版本的操作方式。

绘图与图片识别

商店版准备包随软件提供本机计算和 TeX 编译组件，不需另装 MacTeX；任意外部宏包、用户字体或站外工具路径不保证可用。实际支持范围请查看顶部“操作指南”。

本机 Apple Vision 文字提取与在线公式识别分开。在线识别需要您核对选定图片和接收服务，并逐次同意发送；服务提供者按其约定处理资料。免费状态也可打开“帮助 → 隐私与支持”查看本机说明。
